Basic auth

There's no login step. This page builds Authorization: Basic base64(username:password) and sends it on every request. Users are listed in auth/credentials.txt. See auth/README.md §4.

1. Send the password with each request

Try alan / enigma on /api/admin to get 403 (known, not allowed), and a wrong password to get 401 (unknown). Watch the server log: every click runs the slow password hash again.

2. Send no header

3. Let the browser do it

Open /api/me as a navigation. The server answers 401 + WWW-Authenticate, and the browser shows its own login popup. Log in, come back, and click step 2 again: now it works, because the browser caches the credentials and adds the header itself. There's no logout button. The only way out is to close the browser.
