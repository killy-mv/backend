JWT

Log in once and get a signed token that contains who you are. This page attaches it as Authorization: Bearer ... and the server only checks the signature, with no lookup. The access token lives for 60 seconds. A refresh token in an HttpOnly cookie gets you a new one. See auth/README.md §6.
